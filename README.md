# Notes de vidéos

Une maquette statique minimale pour publier des synthèses de vidéos à partir de sous-titres. Ouvrir `index.html` dans un navigateur suffit.

Le site est publié automatiquement avec GitHub Pages à chaque mise à jour de `master`.

La liste des vidéos est dans `index.html`, dans l'élément `.video-list`. La synthèse affichée utilise du contenu fictif à remplacer.
